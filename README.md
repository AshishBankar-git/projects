# 🏥 Clinic Reception Assistant

A modern clinic management application designed to simplify **patient registration, digital case-paper creation, appointment booking, and patient history management**.

## 📌 Problem Statement

Clinic reception staff often handle patient registration, case papers, appointment scheduling, and record lookup manually. This can make routine tasks slower and make previous patient information harder to access.

## 💡 Solution

Clinic Reception Assistant provides a centralized digital workflow for clinic staff:

1. Register new patients
2. Generate a unique Patient ID
3. Create a digital case paper for a visit
4. Select a doctor
5. View available appointment slots
6. Book an appointment
7. View patient history
8. Manage daily appointments

## ✨ Core Features

- 👤 Patient registration and search
- 📄 Digital case papers
- 📅 Appointment booking and scheduling
- 👨‍⚕️ Doctor management
- 📊 Dashboard and basic reports
- 🔎 Patient history

## 🧭 Main Workflow

```text
New Patient
    ↓
Patient Registration
    ↓
Patient ID Generated
    ↓
Create Case Paper
    ↓
Select Doctor
    ↓
Select Date & Available Slot
    ↓
Confirm Appointment
    ↓
Patient History Updated
```

For an existing patient:

```text
Search Patient
    ↓
Patient Profile
    ↓
New Visit
    ↓
Create Case Paper
    ↓
Book Appointment
```
